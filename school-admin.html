Important notes

  • Run the supplied SQL in Supabase SQL Editor before using Classes & streams, Exams & marks, or Teacher directory.
  • Back up your database before changing existing student fields.
  • Use Supabase Auth; never store passwords in the school tables.
  • RLS policies must be tested with separate school accounts before real student data is entered.
  • This page uses your existing msys_students, msys_schools, msys_user_profiles and msys_student_records tables. Student field names can differ between installations; see the compatibility note below if loading students fails.
